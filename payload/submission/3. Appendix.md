## Why Local Cursor (Not Only CoderPad)

CoderPad’s AI Assist context is limited to about **200k tokens**. Heavy assessment load (screenshots, full tree, multi-file edits, write-up) burns that budget.

**Decision:** use CoderPad as the official runtime / paste target; do heavy editing in **local Cursor** with **[cursor-prime](https://github.com/xnoahwang/cursor-prime)** already installed.

**Not used:** a separate in-pad rule pack that duplicates cursor-prime. This project ships **code + `submission/` + inline comments**; full rules live in the cursor-prime repo.

## Cursor-Prime (Highlights for Reviewers)

Local work followed [cursor-prime](https://github.com/xnoahwang/cursor-prime). Summarize only what mattered for *this* submission; link the repo for details.

### Discipline

- **Plan Gate** — plan → wait for **`GO`** → then edit.
- **Surgical changes** — only files on the pre-flight list.
- **Verify receipt** — real command transcript before “done.”
- **Delta Report** — files changed / outside plan / verify result.

### Maintainability

- **Inline comments** — file headers + “why” on non-obvious behavior.
- **`1. Handover.md`** — newcomer can run and navigate without the chat.
- **`2. Reflection.md`** — thought process, hard/easy, tradeoffs (recruiter ask).

### Not Copied Into the Assessment Repo

- Full `behavior` / maintainability rule text (already in cursor-prime).
- Cursor slash commands / machine-local config.

## Workflow / How This Was Done

Local conductor: `meta-instruction.md` (not uploaded). Chat steps in Chinese; one step at a time.

### Phase A — Capture tree

1. Screenshot CoderPad file tree only; share into local Cursor.

### Phase B — Empty tree + paste

2. Recreate empty tree; human pastes pad sources file-by-file.

### Phase C — Runnable local

3. Assignment install/deps; smoke or starter tests green (or blocker noted).

### Phase D — Requirements → plan → GO

4. Confirm requirements checklist; Plan Gate → **`GO`** → implement with comments + growing `submission/`.

### Phase E — Review + polish

5. Human review/fixes; refresh Handover / Reflection (incl. abandoned approaches) / Appendix sync list.

### Phase F — Return to pad

6. Paste/replace using **Files to Sync** (exclude `meta-instruction.md`); run official pad tests.
